# Contribution guidelines

Thanks for helping make this list better. To keep it useful:

- **Quality over quantity.** Add things you have used or would recommend, not everything that exists.
- **Active projects only.** Repositories must not be archived, and should have had activity in the last 12 months (older is fine for finished, stable references).
- **One item per pull request,** in the right section, following the existing format:
  `- [Name](link) - Description ending with a period.`
- **Keep descriptions short** and factual; no marketing language.
- **Mark paid resources** with "(paid)".
- **Check the link** works before submitting.

Found a dead link or an archived project? Please open an issue or a pull request to remove it.
